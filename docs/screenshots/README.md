# 畫面截圖(README 用)

這個資料夾專門放根目錄 README 裡引用的截圖。**不要放到 `public/`**——`public/` 的東西會被 Next.js 當成靜態資源一起部署上線,截圖只是文件用途,沒必要讓線上站台扛這些體積。

## 現有檔案

| 檔名       | 內容                                                    | README 位置 |
| ---------- | ------------------------------------------------------- | ----------- |
| `map.png`  | `/map` 海況地圖:台灣 SVG 海圖 + 25 區標記 + 右側詳情面板 | 開頭        |
| `seas.png` | `/map` 下半部的海域清單(可排序)+ 右側判定依據           | 開頭        |

兩張都放在 README 最上面(標題與簡介之後、頁面連結表格之前),進 repo 第一眼就看得到。

## 規格

- 格式:PNG(截圖)或 GIF(操作錄影)
- 寬度:1440px 以上,GitHub 會自動縮放
- 單檔大小:盡量壓在 1MB 以內,整個 repo 才不會肥起來(壓縮可用 [squoosh.app](https://squoosh.app))
- 深色 / 淺色:全站只有一套深色配色,截一種就好

## 加新圖

1. 把檔案丟進這個資料夾(建議檔名:`home.png`、`about.png`、`demo.png`)
2. 在根目錄 `README.md` 加一行:

```markdown
![說明文字](docs/screenshots/檔名.png)
```

路徑用相對路徑(`docs/screenshots/...`),GitHub 和本機 Markdown 預覽都讀得到。
